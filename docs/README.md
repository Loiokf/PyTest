# geometric_lib

## Общее описание решения

**geometric_lib** - это библиотека на языке Python для вычисления геометрических характеристик фигур:

- круга;
- прямоугольника;
- квадрата;
- треугольника.

### Основные возможности
- Вычисление площади и периметра для 4 типов фигур.

### Технологии
- Язык программирования: Python
- Стандартная библиотека: `math`
- Система контроля версий: Git
