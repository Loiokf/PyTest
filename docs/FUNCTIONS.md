# Описание функций библиотеки geometric_lib

## circle.py

### area(r)
Площадь круга по радиусу r.

Параметры: r - радиус
Возвращает: float - площадь
Формула: π * r ** 2
Пример: area(3) -> 28.274333882308138

### perimeter(r)
Длина окружности по радиусу r.

Параметры: r - радиус
Возвращает: float - длина окружности
Формула: 2 * π * r
Пример: perimeter(3) -> 18.84955592153876

---

## rectangle.py

### area(a, b)
Площадь прямоугольника по сторонам a и b.

Параметры: a, b - стороны
Возвращает: float - площадь
Формула: a * b
Пример: area(3, 5) -> 15

### perimeter(a, b)
Периметр прямоугольника по сторонам a и b.

Параметры: a, b - стороны
Возвращает: float - периметр
Формула: 2 * (a + b)
Пример: perimeter(3, 5) -> 16

---

## square.py

### area(a)
Площадь квадрата со стороной a.

Параметры: a - сторона
Возвращает: float - площадь
Формула: a²
Пример: area(4) -> 16

### perimeter(a)
Периметр квадрата со стороной a.

Параметры: a - сторона
Возвращает: float - периметр
Формула: 4 * a
Пример: perimeter(4) -> 16

---

## triangle.py

### area(a, h)
Площадь треугольника по стороне a и высоте h, проведённой к ней.

Параметры: a - сторона, h - высота к a
Возвращает: float - площадь
Формула: a * h / 2
Пример: area(6, 4) -> 12.0

### perimeter(a, b, c)
Периметр треугольника по трём сторонам.

Параметры: a, b, c - стороны
Возвращает: float - периметр
Формула: a + b + c
Пример: perimeter(3, 4, 5) -> 12
